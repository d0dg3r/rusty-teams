# manage-team-page Specification

## Purpose

Teams können nativ verwaltet werden: eine Manage-Team-Seite zeigt die Member-Liste.

## Requirements

### Requirement: Native manage team page
The application SHALL provide a native Manage team page that lists team members.

#### Scenario: Open manage team
- **WHEN** the user opens Manage team for a team they can manage
- **THEN** a native page shows the member list for that team
